# Krusty 3.2.0 release

Date: 2026-11-23. Status: proposed.

## Scope and increment

Krusty 3.2.0 adds two public Rust functions from [#258](https://github.com/starknet-innovation/krusty-kms/pull/258).
`selector_from_name` computes the same entrypoint selector as starknet.js.
`verify_stark_signature` verifies Stark ECDSA signatures against an x-coordinate
public key. These additions require a minor version bump.

The release also includes dependency updates from
[#255](https://github.com/starknet-innovation/krusty-kms/pull/255) and
[#259](https://github.com/starknet-innovation/krusty-kms/pull/259), plus CI
maintenance. The WASM npm package takes the workspace version and ships the
existing JavaScript API.

## Internal dependency ranges

Keep the existing `3.0.0` lower bounds. No workspace dependent uses either new
Rust function. Update the root lockfile and both standalone memory-probe
lockfiles to record the new workspace version.

## Verification and publication

Verify the dated changelog, package all eight publishable crates, and run
`bash tools/check.sh all`. Independently review the release diff before opening
the pull request.

Merging the release PR starts the protected npm workflow for
`@starknetfoundation/krusty-kms-wasm@3.2.0`. A maintainer can then tag the
merged commit `v3.2.0` to start the protected crates.io workflow. Follow the
[release playbook](../crates-release.md) for approval and registry verification.
