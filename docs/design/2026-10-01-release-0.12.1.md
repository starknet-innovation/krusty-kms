# Rust workspace release 0.12.1

## Context

The latest published Rust workspace version is 0.12.0, on both crates.io and npm
(`@starknetfoundation/krusty-kms-wasm`). Since then, #162 made the WASM keypair
types zeroize their private keys on drop. Its design is in
[`2026-10-01-wasm-keypair-zeroize.md`](2026-10-01-wasm-keypair-zeroize.md).
The other merged changes are a WASM README note (#161) and dependency lockfile
bumps (#158, #159, #160).

## Decision

Release the Rust workspace as 0.12.1. The patch increment fits a security fix
with no API change. All workspace crates inherit the same version. Internal path
dependency requirements stay at 0.12.0 because Cargo's caret range for 0.12.0
already includes 0.12.1.

The fix is only in `krusty-kms-wasm`, which crates.io does not receive. The npm
package takes its version from the workspace, and `publish-npm.yml` skips a
version that is already published, so the fix reaches npm only through this
version bump. The eight crates.io crates are republished with no source change.
