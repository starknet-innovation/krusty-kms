# Rust workspace release 0.12.0

## Context

The latest published Rust workspace version is 0.11.0. The merged account-class
work in #149 adds discovery and inspection APIs and changes how the WASM and
gateway surfaces handle Braavos implementation class hashes. Its design is in
[`2026-09-21-account-class-roles.md`](2026-09-21-account-class-roles.md).
The unreleased contract-address bound fix is included in this release too.

## Decision

Release the Rust workspace as 0.12.0. The minor increment reflects the
user-visible behavior changes in a pre-1.0 library. All workspace crates inherit
the same version. Internal path dependency requirements move from 0.11.0 to
0.12.0 because Cargo's pre-1.0 caret range for 0.11.0 excludes 0.12.0. The
release PR changes versions, the lockfile, and the dated changelog; the feature
and fix implementations were merged separately.

The WASM npm package has its own version and release workflow.
