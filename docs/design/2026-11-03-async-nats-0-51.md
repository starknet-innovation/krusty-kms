# Bump async-nats to 0.51

Date: 2026-11-03. Status: accepted. Origin: Dependabot PR 191.

## Problem

`async-nats` is the NATS client behind `krusty-kms-client`'s optional `nats`
feature. 0.51.0 fixes several panics and hangs in JetStream, KV, Object Store
and Service, bounds JetStream API requests by the context timeout when one is
set, and redacts secrets from `ConnectInfo`'s `Debug` output. The guardrails
require a design note for any dependency manifest change.

## Contract

No Krusty public API, FFI or WASM surface changes; only
`crates/client/Cargo.toml` and `Cargo.lock` move.

- `async-nats` `0.50.0` → `0.51.0`, still optional and only under the `nats`
  feature. Upstream calls it a minor release because it adds error-kind
  variants and public consumer fields and raises its MSRV to 1.89, inside
  this workspace's 1.92 floor.
- Lockfile: `tokio-websockets` `0.10.1` → `0.13.3` (upstream's websocket
  clean-up), `sha1_smol` `1.0.1` is added, and both `webpki-roots` versions
  drop out of the graph.

## Verification

The `msrv`, `check` (which builds and lints `krusty-kms-client` with
`--features nats`), test and `cargo-deny` jobs pass on the bump.
