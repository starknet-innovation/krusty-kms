# Krusty 0.13.0 release

Date: 2026-10-07. Status: accepted.

Release the merged Starknet 0.20.0 dependency reduction and WASM entropy-error
handling changes. Use a pre-1.0 minor version because the exposed upstream Rust
provider/account/core/signer types require consumers to upgrade together.

All workspace packages inherit 0.13.0. Internal path dependency requirements
move from 0.12.0 to 0.13.0 so packaged crates resolve the same release family;
third-party lockfile versions are unchanged. Move the existing Unreleased notes
into the dated 0.13.0 changelog entry. No implementation or export changes occur
in this release-preparation PR.

Package all eight publishable crates before merging. Tag only the merged main
commit as v0.13.0, then use the protected crates-io GitHub Actions OIDC workflow.
Trusted publishers were confirmed by the maintainer, and GitHub environment
protections were verified live. Keep the release tag immutable; retry the same
workflow for partial publication, or use a new patch version for source fixes.
