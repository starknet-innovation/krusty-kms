# Krusty 0.10 release

Krusty keeps one workspace version for its Rust crates and generated WASM
package. crates.io is at 0.7.0, while the separately published WASM package
already has versions through 0.9.6. Version 0.10.0 is therefore the first
unified version that advances both registries without colliding with an
existing package.

The release exposes the existing mnemonic-bound NIP-44 and NIP-59 application
envelopes through the published WASM package. It adds no second cryptographic
implementation or new secret boundary. The direct ChaCha20 dependency also
advances within its existing 0.10 API to the supported 0.10.2 patch because
0.10.1 has been yanked.

The npm artifact remains built and tested from `main`, then published through
the protected main-only npm environment. Rust crates remain released from the
same versioned source through the signed-tag workflow.
