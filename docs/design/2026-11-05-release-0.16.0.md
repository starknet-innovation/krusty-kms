# Krusty 0.16.0 release

Date: 2026-11-05. Status: accepted.

Release the fixes merged since 0.15.0. Use a pre-1.0 minor version because
the increment changes public Rust API that dependents on `^0.15.0` must opt
into:

- `EthSigner::public_key_xy()` returns exact `EthCoordinate` values instead
  of `Felt` values reduced modulo the Stark prime (#202).
  `cargo-semver-checks` does not detect a changed return type on an inherent
  method, so the minor bump is a reviewer decision recorded here.

The same range carries endpoint-safe `Tx` provider errors, strict public-key
hex parsing across the WASM, C ABI and common boundaries, and building the
`wasm-bindgen` CLI from crates.io in CI and npm publishing (#198, #199, #200,
landed as #201).

## Why 0.16.0 and not 1.0.0

1.0.0 was considered. The 0.15.0 notes promised two breaking changes for
0.16.0 that have not landed:

- removing the deprecated `felt_to_u256_pair`;
- bounding `krusty-kms-client` RPC response bodies (audit M-2), which can
  change the public `JsonRpcClient<HttpTransport>` type.

After 1.0.0 either change would need 2.0.0. They are deferred again and
planned before 1.0.0. The 0.16.0 changelog entry says so, because the
0.15.0 entry still names 0.16.0.

## Dependency ranges

All workspace packages inherit 0.16.0. Internal `krusty-kms-*` path
dependency requirements move from 0.15.0 to 0.16.0, because pre-1.0 caret
ranges on 0.15.0 exclude 0.16.0. Path dependencies without a version
requirement stay unchanged.

## Publication

No implementation or export changes occur in this release-preparation PR.
`Cargo.lock` moves `hyper` from 1.8.1 to 1.12.0, which drops the
unmaintained `pin-utils` (RUSTSEC-2026-0441, published after 0.15.0) so
`cargo audit --deny warnings` passes; library dependents resolve their own
lockfiles.
Package all eight publishable crates before merging. Tag only the merged
`main` commit as `v0.16.0`, then use the protected crates.io GitHub Actions
OIDC workflow. Merging to `main` also starts the npm publish of
`@starknetfoundation/krusty-kms-wasm` 0.16.0, gated by the `npm`
environment. Keep the release tag immutable; retry the same workflow for
partial publication, or use a new patch version for source fixes.
